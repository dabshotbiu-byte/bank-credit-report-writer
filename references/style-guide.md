# Template-derived writing style

This guide abstracts the four supplied reports. It does not preserve their customer-specific facts.

## Voice

- Use a decisive first-person institutional voice: “经营团队认为/经经营团队核实/我行拟…”.
- Refer to the borrower as “申请人” or a defined short name.
- Put the conclusion first, followed by evidence and operating explanation.
- Prefer concrete causal chains: event → account/product effect → cash-flow effect → credit implication.
- Use short numbered reasons for the facility conclusion and specific subsections for detailed analysis.
- Write as the relationship manager who has completed the investigation, not as an assistant describing what it read.

## Evidence density

A useful paragraph normally contains a period, amount or ratio, named counterparty/product, transaction term, and the analyst's interpretation. Compare at least two periods when explaining change. Tie forecasts to orders, installed base, capacity, contracts, seasonality, price and margin assumptions.

## Preferred constructions

- “申请人2024年及2025年分别实现……，同比……，主要受……影响。”
- “从资金占用看，上游……、下游……，因此流动资金主要沉淀于……。”
- “前五大客户合计占比……，其中……；集中度较高，但……构成回款基础/放大单一客户风险。”
- “在……情景下，预计期末货币资金为……，扣除一年内到期刚性债务后为……。”
- “本次授信主要叙做理由如下：1）……；2）……；3）……。”
- “综合收入、开票、回款及应收账款变动，经营团队认为……”
- “上述业务安排使资金主要沉淀于……，与本次流动资金需求相匹配。”

## Reasoning standard

Use `已核实事实 → 交叉验证 → 原因解释 → 现金流/偿债影响 → 授信判断`. Do not stop at summarizing source content. When several facts support one conclusion, integrate them into one argument rather than listing where each fact came from.

Public-source names and query dates belong in the working paper. Put an authoritative industry source in a footnote, table note or figure caption when attribution is necessary. In the main sentence, lead with the business fact or conclusion instead of narrating the act of searching.

## Prohibited in a finished report

- Source-narration openings: “材料显示”“公司提供的材料显示”“公司提供的材料里显示”“根据公司提供的材料”“官网显示”“公开资料显示”“从材料看”。
- Unfinished-work language: “建议补充”“建议提供”“需补充”“需核实”“待核实”“待确认”“有待确认”“后续核查”“进一步核实”“建议进一步核查”“相关情况不详”“尚未取得”“后续关注”。
- Weak speculation used in place of analysis: “据称”“大概”“或许”“可能为”“应该是”“不排除”。
- Unsupported promotional adjectives: “领先”“唯一”“顶尖”“前景广阔”. Attribute and date third-party rankings.
- A table followed by prose that merely repeats every number.
- Treating a good customer name as proof of timely payment without terms and collection evidence.
- Treating high growth as automatically favorable without margin, inventory, receivable and cash analysis.
- Hiding risks. State them directly and explain verified mitigation or facility controls.

## Completeness rule

If decisive evidence is insufficient, resolve it before final drafting through one consolidated question set. If a non-decisive detail remains unavailable, omit the unsupported assertion or narrow the conclusion to the verified period and scope. Never fabricate certainty and never transfer the unfinished investigation to the approver through a request sentence.

## Typography and heading style

- All editable report text uses 楷体: title, headings, body, numbered items, tables, captions, headers and footers. Set both the East Asian font (`楷体`) and the Latin font (`KaiTi`) at the document-default, style and run levels so Word and LibreOffice render consistently. Retain Symbol/Wingdings only for a glyph that would otherwise break.
- Unless the user expressly requires another system, use `一、大标题` → `1.中标题` → `1）小标题`. Do not mix `1.1`, `（一）`, `1、` or unnumbered bold pseudo-headings.
- Use real Word heading styles and numbering definitions. Do not type Markdown markers into the report.
- Flowchart text uses `KaiTi, STKaiti, 楷体` in that order; money arrows remain red and goods/service/data arrows black.
